# Food Calorie Estimator

An AI/ML-based application that recognizes food from meal images and provides estimated nutritional information.

## Project Overview

The Food Calorie Estimator uses image classification to identify food from a meal photo. The predicted food class is mapped to nutritional data, allowing the application to estimate calories, protein, carbohydrates, and fat based on the selected portion size.

The application will also allow users to log meals, set a daily calorie goal, and monitor daily and weekly calorie intake.
